# Project Synora

Project Synora is an opt-in developer platform for portable player identity in video games.

> Players keep their identity. Games keep their worlds. The platform connects the two.

## Current phase

This repository is in design review. Product and architectural decisions must be recorded before substantial implementation begins.

No game, engine, publisher, or franchise integration should be claimed unless it has been explicitly built, authorized, and tested.

## Repository map

- `docs/00-product-engineering-foundation.md` — original working specification
- `docs/04-design-review-v0.1.md` — initial engineering review and recommendations
- `docs/decisions/` — architecture decision records (ADRs)
- `docs/security/` — threat model, privacy, and data-classification work
- `docs/diagrams/` — architecture and data-flow diagrams

Application code will be scaffolded only after the initial architecture review gate is approved.
