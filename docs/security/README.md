# Security and Privacy Workstream

The project must complete these artifacts before accepting real player facial captures:

- data-classification register;
- system and trust-boundary diagram;
- identity capture and representation data-flow diagram;
- threat model;
- raw capture retention and deletion policy;
- processor/vendor inventory;
- incident-response outline;
- age eligibility and identity ownership policy.

Synthetic fixtures must be used until the applicable review gates are approved.
