# ADR-007: First engine SDK

**Status:** Proposed  
**Date:** 2026-08-12

## Context

An engine demo matters, but building an SDK before the authorization and asset contracts settle would create rework.

## Decision

Defer engine SDK implementation until the web-based synthetic proof is approved. Unity remains the proposed first engine target after that gate.

## Rationale

The platform lifecycle is the first risk. Unity is a practical initial adapter once the contracts are stable.

## Consequences

Milestones 0 through 4 make no engine compatibility claim. The demo uses controlled Synora-owned clients.

## Reversal conditions

Choose another first engine if a validated partner, required fidelity target, or team expertise changes the evidence.
